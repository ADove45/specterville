# Pictures

Save each picture here, named exactly like the key in `PROMPTS.md` (for example `apartment.jpg`).
Wide 16:9 works best, about 1600 pixels across. `.jpg`, `.png` and `.webp` all work.
A page with no picture simply shows no picture. To see labeled empty slots while you work, set `SV.PLACEHOLDERS = true` in `js/specterville/art.js`.
